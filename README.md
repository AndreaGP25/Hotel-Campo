# Sistema Web de Gestión Hotelera

Aplicación web desarrollada para gestionar las operaciones del hotel, incluyendo la administración de habitaciones, reservas y servicios adicionales. Este proyecto se creó como parte de una práctica académica de desarrollo de software.

### Descripción general

El sistema permite a los usuarios ver las habitaciones disponibles, realizar reservas y explorar los servicios del hotel. También incluye un panel administrativo donde el personal puede gestionar la información de las habitaciones y actualizar los datos del sistema.


#### Usuario
- Ver habitaciones disponibles
- Hacer reservas
- Explorar los servicios del hotel
- Galería de imágenes y sección de preguntas frecuentes
- Inicio de sesión y recuperación de contraseña

#### Panel de administración
- Crear, actualizar y eliminar habitaciones (CRUD)
- Gestionar la disponibilidad de habitaciones
- Ver información de reservas

#### Tecnologías utilizadas
- PHP
- HTML5
- CSS3
- JavaScript
- MySQL
